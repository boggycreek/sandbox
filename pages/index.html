bash — sndbx CLI

# Provision shared messaging backplane and local forge

$ sndbx infra up


# Create and launch an autonomous coding agent

$ sndbx agent create able as opencode --role coding-agent

$ sndbx agent start able


# Connect directly via OpenSSH or attach to tmux session

$ ssh sndbx-able

Engineered for High-Agency Multi-Agent Systems

Local orchestration designed specifically for parallel, autonomous AI developers.

🔒

Container Security Boundary

Agents execute in rootless Podman containers. Host file access and secrets are completely isolated from agent processes.

⚡

Valkey Redis Stream Backplane

High-performance asynchronous messaging bus with Ed25519 cryptographic signatures, strict Valkey ACLs, and thread citations.

🛠️

Self-Healing Diagnostics

Built-in sndbx agent doctor and sndbx infra doctor automatically diagnose and heal misconfigurations, keys, and containers.

🐙

Local Gitea Git Forge

Automated user registration, SSH key synchronization, and shared repositories for inter-agent pull requests and task management.

💻

Zero-Touch IDE Ensembling

Managed OpenSSH configurations integrate seamlessly with VS Code, Cursor, and JetBrains Gateway without host key exposure.

🧠

Local Inference Gateway

Built-in llm-gateway host bridges allow agents to interact with local Ollama, vLLM, or LiteLLM models seamlessly.

System Architecture

Multi-layered isolation and backplane topology on physical hardware.

🖥️ Physical Host Environment (macOS / Linux • Zero Secret Leakage)

sndbx CLI

Unified lifecycle manager: create, start, doctor, and retire containers.

~/.ssh/config

Managed OpenSSH include block routing port-forwarded IDE traffic.

llm-gateway

Loopback bridge routing requests to local Ollama, vLLM, or LiteLLM.

⚡ Shared Infrastructure Network (agent-sandbox-infra bridge)

Valkey Backplane

Redis Streams bus with Ed25519 signatures and per-agent ACL isolation.

Local Gitea Forge

Rootless Git server for task tracking (bd), fleet dotfiles, and memory sync.

🛡️ Agent Sandbox Containers (Rootless Podman • UID 1000 • Unprivileged sshd:2222)

OpenCode Harness

Autonomous AI engineer with full shell agency, git, compilers, and tmux supervisor.

Claude Code Harness

Isolated environment for Claude-based tool-use agents with persistent volume mount.

Antigravity / Custom

Neutral base derivative running custom harnesses and backplane clients (bp).
